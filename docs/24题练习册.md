# 自习站 · 24题练习册

建议每次选一个学科独立作答，再核对解析。以下为原创基础练习。


## 把条件用完整，把计算做扎实

先独立尝试，再看提示。每题写出使用定理的条件；涉及极限时，特别留意相减抵消与定义域。


### 01. 设 f 在 [0,1] 连续、在 (0,1) 可导，且 f(0)=0、f(1)=1。证明存在 c 属于 (0,1)，使 f'(c)=2c。请写出辅助函数并验证定理条件。

提示：目标式可以改写成某个函数的导数为零。找一个导数为 2x、端点值又合适的函数。


### 02. 计算 x -> 0 时 (e^x-1-x)/x^2 的极限。有人把 e^x-1 等价替换成 x，认为答案为 0；指出这一步的问题，并保留足够阶数完成计算。

提示：分子的一阶项会抵消，必须知道 e^x 的二阶项。


### 03. 对实数 x，定义 F(x)=int_0^(x^2)(1+t^2)dt。求 F'(x) 与 F'(1)，并说明为什么不能直接把被积函数中的 t 换成 x 就结束求导。

提示：先把变上限积分看作关于上限 u 的函数，再对 u=x^2 使用链式法则。


### 04. 对任意 x>0，证明 ln(x)<=x-1，并确定等号成立的条件。要求构造一个函数，用导数符号解释全定义域上的大小关系，不能只验证 x=1 附近。

提示：令 h(x)=x-1-ln(x)，观察它在 (0,1) 和 (1,+infinity) 上的单调性。


### 05. 求级数 sum_(n=1)^infinity 1/[n(n+1)] 的和。请先求前 N 项和再取极限，并解释“通项趋于 0”为什么不能单独作为本题级数收敛的理由。

提示：将 1/[n(n+1)] 拆成两个相邻倒数之差，先只处理有限项。


### 06. 设 f 在 [-1,1] 连续、在 (-1,1) 二阶可导，且 f(-1)=f(0)=f(1)=0。证明存在 c 属于 (-1,1)，使 f''(c)=0，并说明所需的三次罗尔定理分别用在哪里。

提示：先分别在 [-1,0] 与 [0,1] 上使用定理，再对得到的两个导数零点之间使用定理。


### 参考解析


**01 答案**：取 F(x)=f(x)-x^2，由罗尔定理得到所需的 c。

F 在 [0,1] 连续、在 (0,1) 可导，且 F(0)=0、F(1)=1-1=0，满足罗尔定理。故存在 c 属于 (0,1)，使 F'(c)=f'(c)-2c=0，即 f'(c)=2c。这里不需要额外假设 f' 连续。

易错：不能直接对 f 使用罗尔定理，因为 f(0) 与 f(1) 不相等。


**02 答案**：极限为 1/2；相减抵消时，不能直接用等价量忽略高阶项。

当 x -> 0 时，e^x=1+x+x^2/2+o(x^2)。减去 1+x 后，分子为 x^2/2+o(x^2)，除以 x^2 即得 1/2。关系 e^x-1 与 x 等价只确定一阶行为；相减后，一阶项消失，原先忽略的二阶项成为主项。

易错：不能把乘除中的等价替换规则机械搬到存在抵消的加减式中。


**03 答案**：F'(x)=2x(1+x^4)，F'(1)=4。

被积函数 1+t^2 在实数上连续。令 G(u)=int_0^u(1+t^2)dt，则微积分基本定理给出 G'(u)=1+u^2。又 F(x)=G(x^2)，链式法则给出 F'(x)=(1+x^4)2x。也可先积分得 F(x)=x^2+x^6/3，再求导核对。

易错：上限是 x^2，既要代入 x^2，也要乘上限的导数 2x。


**04 答案**：不等式成立，且等号仅当 x=1 时成立。

令 h(x)=x-1-ln(x)，定义域为 x>0，导数 h'(x)=(x-1)/x。当 0<x<1 时导数为负，当 x>1 时导数为正，所以 h 先严格递减后严格递增，在 x=1 取得唯一最小值 h(1)=0。因此 h(x)>=0，即得到原不等式及等号条件。

易错：只算出 h'(1)=0 不能直接断定它是全局最小值，仍需分析导数符号。


**05 答案**：前 N 项和为 N/(N+1)，所以无穷级数的和为 1。

利用 1/[n(n+1)]=1/n-1/(n+1)，有限求和时中间项抵消，得到 S_N=1-1/(N+1)。令 N 趋于无穷，S_N 趋于 1，故级数收敛且和为 1。通项趋于 0 只是必要条件；调和级数的通项也趋于 0，却仍然发散。

易错：不要先把两个发散的无穷级数分别求和，再相减；抵消应在有限部分和中完成。


**06 答案**：先在两侧得到 f'(a)=f'(b)=0，再在 [a,b] 上对 f' 使用罗尔定理。

前两次应用得到 f'(a)=f'(b)=0。由于 f 在 (-1,1) 二阶可导，f' 在该区间可导，因而在 [a,b] 连续、在 (a,b) 可导。第三次对 f' 应用罗尔定理，得到某个 c 属于 (a,b)，使 f''(c)=0；而 (a,b) 包含于 (-1,1)。

易错：结论只保证某个 c 存在，不能断言 c=0，也无需假设 f'' 连续。


## 把位模式还原成含义

先写明位宽、编址单位与时间模型，再计算。下面所有容量单位采用 B、KiB、MiB；所有进制均在题目中明确标出。


### 07. 两个8位补码为01100100和00101000。仅保留相加结果的低8位，分别写出数学和、结果位模式及其有符号值，并判断是否发生有符号溢出。

提示：先把操作数读成十进制整数，再检查同号相加后结果的符号。


### 08. 某存储器使用20位完整地址，按字节编址，全部地址组合均可访问且没有保留区。最多能寻址多少B、KiB和MiB？若字长为16bit，容量会因此翻倍吗？

提示：先数地址个数，再乘每个地址对应的字节数；字长与编址单位分开看。


### 09. 直接映射Cache有4行，行号为0到3，每行放一个主存块，初始全无效。依次访问主存块3、7、8、8、3，写出对应行号、各次命中情况和总命中率。

提示：主存块j映射到j mod 4行；每次缺失后，该行原有块会被替换。


### 10. 单级Cache命中时间为2 ns，缺失率为5%，每次缺失额外增加60 ns。求平均访存时间；按此平均模型，1000次访问的预期总时间是多少？

提示：这里的60 ns是额外代价，已经排除了本次访问原本需要的2 ns。


### 11. 某程序执行10^9条指令，其中50%的CPI为1，30%为2，20%为4。CPU频率为2 GHz，忽略其他等待时间。求加权平均CPI、总时钟周期数和CPU执行时间。

提示：按指令条数比例加权CPI；2 GHz表示每秒2*10^9个时钟周期。


### 12. 假设每字节8bit，uint32_t恰为32bit，机器采用小端序。变量v的值为0x12345678，用unsigned char指针p指向v的起始地址。p[0]和p[3]分别是多少？

提示：unsigned char按字节查看对象表示；小端序把最低有效字节放在最低地址。


### 参考解析


**07 答案**：数学和为140；低8位为10001100，按8位补码解释为-116；发生有符号溢出。

两个操作数分别为100和40，真实和140超过8位补码上限127。截断后位模式的无符号值是140，补码值则为140-256=-116。同号正数相加却得到负号，足以判定有符号溢出。

易错：最高位没有向外进位，也可能发生有符号溢出；无符号进位与有符号溢出不能混判。


**08 答案**：容量为1048576 B=1024 KiB=1 MiB；字长为16bit不会使该容量翻倍。

20位地址共有2^20种组合，每个地址对应1 B，因此容量为2^20 B。1 KiB=1024 B，1 MiB=1024 KiB。题目已经规定按字节编址，16bit字长只表示一个字占2 B，不能把每个地址再当成一个字。

易错：按字节编址时，每个地址对应1 B；只有改为按字编址，才需按每字字节数换算容量。


**09 答案**：行号依次为3、3、0、0、3；依次为缺失、缺失、缺失、命中、缺失；命中率为1/5=20%。

首次访问块3占用第3行，块7随后替换它。块8放入第0行，再次访问块8时命中。最后块3仍需替换第3行中的块7，因此缺失。映射到同一行并不表示命中，还必须同时匹配有效位与块标记。

易错：块3曾经访问过，不代表它仍在Cache中；块7已经与它发生了直接映射冲突。


**10 答案**：AMAT=2+0.05*60=5 ns；1000次访问的预期总时间为5000 ns，即5 us。

每次访问都支付2 ns，只有缺失时额外支付60 ns，因此平均再增加3 ns。1000次访问预计有50次缺失，总时间为1000*2+50*60=5000 ns。这是平均模型的预期值，不保证任意一段访问都恰好缺失50次。

易错：不要再给60 ns额外加一次命中时间后，整体代入“命中时间+缺失率*额外代价”。


**11 答案**：平均CPI=0.5*1+0.3*2+0.2*4=1.9；总周期数为1.9*10^9；执行时间为0.95 s。

三类指令的执行次数比例已经给定，因此按0.5、0.3、0.2加权，不能直接对1、2、4取算术平均。总周期数等于指令条数乘平均CPI，再除以每秒2*10^9周期，得到0.95 s。

易错：GHz是每秒周期数，不是每秒指令数；平均CPI不为1时，两者不能直接互换。


**12 答案**：p[0]=0x78，p[3]=0x12；从低地址到高地址的4个字节为0x78、0x56、0x34、0x12。

v共占4个8bit字节，最低有效字节是0x78。小端序将它存放在对象起始地址，因此p[0]读取0x78，p[3]读取最高有效字节0x12。这里按字节观察存放次序，整数v的数值仍为0x12345678。

易错：小端序只改变多字节对象的字节存放次序，不会把每个字节内部的二进制位倒过来。


## 用边界、反例和不变式检验算法

纸上推演时写出数组下标或队列状态。复杂度结论应说明数据结构、输入条件与具体实现。


### 13. 在有序数组 a=[1,2,2,2,5] 中，使用半开区间 [l,r) 寻找首个 >=target 的下标。分别给出 target=2、target=6 和空数组时的返回值，并写出一次循环的更新规则。

提示：答案可以等于数组长度。维护 l 左侧都小于目标、r 及其右侧都不小于目标。


### 14. 有向图有三条边：s->a 权重 5，s->b 权重 1，b->a 权重 1。求 s 到 a 的最短距离及路径；解释普通 BFS 为何可能给出错误结果，以及这里能否使用 Dijkstra。

提示：普通 BFS 按经过的边数分层，不按路径权重之和分层。


### 15. 0/1 背包容量为 6，仅有一件重量 3、价值 4 的物品，最多选择一次。令 dp[c] 初值均为 0，表示容量不超过 c 的最大价值；比较容量正序与倒序更新后 dp[6] 的结果。

提示：转移为 dp[c]=max(dp[c],dp[c-3]+4)。检查更新 dp[6] 时，dp[3] 是否已使用当前物品。


### 16. 快速排序处理 n 个完全相同的元素。若每轮把一个主元单独放好，其他等于主元的元素全放同一侧，写出时间复杂度；随机选主元能否修复此输入？三路划分又会怎样？

提示：分别观察每轮递归子问题的规模，以及是否还需要递归处理“等于主元”的部分。


### 17. 给定静态数组 a=[3,-2,5,1]，构造 prefix[0]=0 的前缀和，求半开区间 [1,3) 与 [2,2) 的和。若随后把 a[1] 改成 4，旧前缀和能否继续正确回答所有区间？

提示：prefix[i] 表示前 i 个元素之和；修改某个元素会影响它之后的哪些前缀值？


### 18. 有向图顶点为 A、B、C、D，边为 A->B、A->C、B->D、C->D。给出全部拓扑序；若新增 D->A，用 Kahn 算法说明为什么不存在拓扑序，并给出邻接表实现的时间复杂度。

提示：拓扑序只要求每条边的起点排在终点前，不要求答案唯一。新增边后先检查各顶点入度。


### 参考解析


**13 答案**：依次返回 1、5、0。初始 l=0、r=n；结束时返回 l。

当 l<r 时取 mid=l+floor((r-l)/2)。若 a[mid]<target，令 l=mid+1；否则令 r=mid。这样保留答案所在边界且候选区间严格缩小。空数组初始 l=r=0，不访问元素；全部元素小于目标时返回 n，不能把它直接当成有效元素下标。

易错：寻找首个位置时，遇到相等元素也不能立即返回 mid，左侧可能还有相同值。


**14 答案**：最短距离为 2，路径为 s->b->a；可使用 Dijkstra，因为所有边权非负。

路径 s->a 只有一条边但权重为 5，路径 s->b->a 有两条边但总权重为 2。普通 BFS 若把首次访问视作最优，会偏向边数较少的路径。Dijkstra 则先确定距离为 1 的 b，再将 a 的暂定距离从 5 松弛到 2，得到正确答案。

易错：“边数最少”与“权重总和最小”在不同边权下不是同一个目标。


**15 答案**：倒序更新得到 dp[6]=4；正序更新会错误地得到 dp[6]=8。

倒序从 c=6 更新到 3，计算 dp[6] 时 dp[3] 仍为旧值 0，因此只加入一次物品。正序从 c=3 到 6 时，dp[3] 先变为 4，随后 dp[6] 又使用这个新值，算成 4+4。该结果相当于把同一件物品选了两次，违反 0/1 条件。

易错：一维压缩后，循环顺序决定转移读到的是上一轮状态还是当前轮新状态。


**16 答案**：该实现为 O(n^2)；随机选主元无济于事；标准三路划分对此输入为 O(n)。

每次线性划分后，两个子问题规模为 0 和 n-1，故总工作量为 n+(n-1)+...+1。元素全相同，任何随机主元的值都一样，不能改变划分规模。三路划分一次收集小于、等于、大于主元的部分，并跳过等值部分的递归，所以只需一次线性扫描。

易错：“随机主元就总有 O(n log n)”忽略了重复元素和划分实现的影响。


**17 答案**：prefix=[0,3,1,6,7]；区间和为 3、0。修改后必须更新前缀和。

[l,r) 的和为 prefix[r]-prefix[l]，得到 6-3=3 与 1-1=0。将 a[1] 从 -2 改成 4 后，prefix[2] 及后续值都应增加 6，新 prefix 为 [0,3,7,12,13]。此时 [1,3) 的和为 9，需更新或重建。

易错：前缀和允许负数；限制在于静态数据，而不是所有元素必须非负。


**18 答案**：原图仅有 A,B,C,D 和 A,C,B,D 两个拓扑序；加边后有环，时间复杂度为 O(V+E)。

原图中 A 必须最先，D 必须在 B、C 之后，所以只有 B、C 可以交换。新增 D->A 后，A、B、C 的入度都为 1，D 的入度为 2，没有入度为 0 的起点。Kahn 算法输出 0 个顶点，少于 V=4，判定存在有向环，因而无拓扑序。

易错：有向图的拓扑序可以有多个；输出顶点数少于 V 才是完整的有环判断标准。


## 把搭配写进自己的句子

每题先尝试完整作答，再对照理由。参考答案允许意思、语法均正确的其他表达；改写时应保留题目要求的结构与原意。


### 19. 用improve的适当形式填空并说明理由：Practice contributes to ___ accuracy. 此处to是什么词性？能否直接填动词原形？

提示：先判断to属于不定式标记，还是固定搭配中的介词。


### 20. 改正句中的介词搭配错误，并保持原意：Despite of being busy, Li kept reading. 请给出一种正确写法，再说明错误发生在哪里。

提示：despite与in spite of意义相近，但它们需要的词数不同。


### 21. 从affect和effect中选词并作必要变化：Noise ___ sleep. It has an ___ on attention. 写出两空答案，并说明各空所需的词性。

提示：第一空需要谓语动词；第二空位于an后，属于has an ... on结构。


### 22. 依次用walk和cycle填空：I used to ___, but now I am used to ___. 句意是过去常走路、现在习惯骑车；说明两个to后形式不同的原因。

提示：区分“过去常常做”与“现在习惯于做”，不要只比较表面的used和to。


### 23. 改写错误句，保留“导师建议我复习笔记”的意思：The tutor suggested me to review the notes. 请使用suggest that从句，并写出从句中的动词形式。

提示：suggest表示建议时，常用doing或that从句，不直接套用tell somebody to do。


### 24. 用a number of和the number of分别翻译：“有若干学生在这里。”“学生人数是30。”写成两个完整句子，并说明为什么两句谓语的单复数不同。

提示：先判断说的是“若干学生”，还是作为一个整体的“学生人数”。


### 参考解析


**19 答案**：填improving。完整句：Practice contributes to improving accuracy.

contribute to表示“有助于”，这里的to是介词。介词后可接名词或动名词，所以应将improve改为improving。不能仅因看见to就套用不定式；本题也可理解为练习有助于提高准确率。

易错：本题要求使用improve作答；如果改用名词，也须保证搭配和句意成立。


**20 答案**：Despite being busy, Li kept reading. 或In spite of being busy, Li kept reading.

despite后直接接名词或动名词，不加of；in spite of则需保留三个词。being busy是动名词结构，表示“尽管很忙”。删去多余的of，或整体改用in spite of，都能保留原意。

易错：不要把两个表达拼接成despite of；本题无须把正确的动名词being改成be。


**21 答案**：两空依次填affects、effect；Noise affects sleep. It has an effect on attention.

第一句主语Noise在这里作不可数名词使用，谓语用第三人称单数affects。第二句冠词an后需要名词effect，has an effect on表示“对……有影响”。这是两词的常见用法，不代表它们只能充当这些词性。

易错：不要漏掉affects的-s，也不要因中文都可译成“影响”就忽略句子中的词性位置。


**22 答案**：两空依次填walk、cycling：I used to walk, but now I am used to cycling.

used to do表示过去的习惯，其后用动词原形walk；be used to doing表示习惯于某事，其中to是介词，其后用动名词cycling。but now明确对比过去和现在，应根据整个结构判断形式。

易错：be used to还可出现在被动语态中；本题已明确表示“习惯于”，应按该含义作答。


**23 答案**：The tutor suggested that I review the notes.

suggest表示“建议”时，可接that从句，从句常用动词原形，或采用should加动词原形。原句把suggest误套成了suggest somebody to do。本题要求明确保留“我”，用that I review可同时表达建议内容与执行者。

易错：不要改为that I reviewed来机械对应主句过去时；本题考查的是表示建议的常用从句结构。


**24 答案**：A number of students are here. The number of students is 30.

a number of加复数名词表示“若干”，说的是多个学生，因此用are。the number of表示“……的数量”，中心含义是一个数量，因此用is。两句虽然都有students，主谓一致的判断依据却不同，不能只看紧邻谓语的名词。

易错：不要把第一句的a写成the后仍用are；冠词变化会改变整个短语的含义和谓语选择。
